    07Si algo falla

    El QR no abre la página en el celular

    1) Revisa que la dirección bajo el QR sea la IP de la computadora (no localhost ni 172.x). Si no, Cambiar dirección. 2) Mismo Wi-Fi en ambos. 3) Si macOS pregunta por conexiones entrantes de Docker, elige Permitir.Permite Docker Desktop Backend en el Firewall de Windows (redes privadas).Abre el puerto 80 en el firewall (sudo ufw allow 80). 4) Si la red de la escuela bloquea, usa el enlace público (paso 06).

    "dependency datos failed to start" o "ignis-datos-1 is unhealthy"

    Pasa si descargaste el proyecto otra vez: la carpeta nueva crea otra contraseña y la base de datos vieja de Docker no la acepta. Reinicia solo la base (se vuelve a cargar sola desde los CSV en ~10 min) y arranca de nuevo:

    bash scripts/ignis.sh reiniciar-datos; bash scripts/ignis.sh iniciar
    .\scripts\ignis.ps1 reiniciar-datos; .\scripts\ignis.ps1 iniciar

    Las versiones nuevas del lanzador ya lo detectan y lo arreglan solas.

    "read-only file system" o "no space left on device"

    El disco está casi lleno. Libera al menos 15 GB, cierra y abre Docker y arranca de nuevo. Si sigue: Docker Desktop → Troubleshoot → Clean / Purge data (borra solo lo de Docker).

    No encuentra "docker"

    Abre Docker Desktop y espera "Engine running". Luego vuelve a abrir el lanzador.

    "No se abrió IGNIS-Mac.command"

    macOS bloquea archivos descargados. Usa Terminal (paso 04) o Ajustes del Sistema → Privacidad y seguridad → Abrir de todos modos.

    "No se puede ejecutar scripts en este sistema"

    Usa el .bat (ya incluye el permiso) o el comando con -ExecutionPolicy Bypass del paso 04.

    Tarda mucho o algo no responde
    bash scripts/ignis.sh registros
    powershell -ExecutionPolicy Bypass -File .\scripts\ignis.ps1 registros

    Busca líneas en rojo. Para salir: Ctrl C.

    Quiero empezar de cero

    Esto borra solo la base de datos de Docker (se vuelve a cargar sola):

    docker compose --profile tunel down -v
